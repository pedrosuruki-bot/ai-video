# AI Video Factory

V1 do estúdio de produção de vídeos long-form.

## Arranque

```bash
npm install
cp .env.example .env.local
npm run dev
```

A V1 inclui análise de roteiro, storyboard, integração OpenAI para análise/TTS e pesquisa Pexels. Renderização FFmpeg e armazenamento persistente entram na próxima etapa.
